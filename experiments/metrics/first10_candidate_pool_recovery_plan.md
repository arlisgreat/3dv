# G15 Candidate-Pool Recovery Plan

Date: 2026-05-19

## Premise Reset

The current `experiments/downstream_datasets/` candidate pools are blocked for
reconstruction training. The error is upstream: the generated/selected pseudo
views are visually invalid before any 3D method sees them.

The next work is therefore candidate-pool recovery, not another RI3D variant.

## Hypothesis

The main recoverable failure is input framing. The prior cutout inputs still
contained too much body, clothing, or full-photo context, so Zero123++ often
rotated a person/card rather than a head.

A tighter head-centered gray-background crop may reduce:

```text
split bodies
rotated photo-card artifacts
large body-only fragments
background leakage
```

This is only a generation premise. It does not validate reconstruction training.
