# Downstream Datasets

This directory contains tool-agnostic pseudo-view datasets for the next 3D reconstruction experiment.

Generated by:

```bash
python3 scripts/build_downstream_dataset.py --overwrite
```

## Variants

```text
raw75_all6/
```

All six raw Zero123++ `steps=75` views for each first10 sample. This is the unsafe baseline.

```text
raw75_budget4/
```

Four raw Zero123++ `steps=75` views selected by CLIP/reliability ranking. This tests whether ranking alone helps.

```text
cutout75_budget4_masked/
```

Subject-cutout Zero123++ `steps=75` views selected by CLIP/reliability budget4 and filtered by trusted-region acceptance. This is the current preferred pseudo-view frontend.

## Per-Sample Layout

Each sample contains:

```text
images/
masks/
metadata.json
```

`metadata.json` records:

```text
sample_id
variant
source_run
selected view indices
azimuth / elevation
image path
mask path
trusted score
reliability score
reject reasons
```

## Intended Comparison

Use these variants for the first downstream 3D reconstruction comparison:

```text
A: LAM single-image baseline
B: raw75_all6 or raw75_budget4
C: cutout75_budget4_masked
```

The target question is whether the safer pseudo-view frontend improves final 3D reconstruction compared with raw pseudo views.

## RI3D Conversion

RI3D does not read this tool-agnostic layout directly. Convert the selected
first2 pilot scenes with:

```bash
python3 scripts/prepare_ri3d_dataset.py --overwrite
```

Converted output:

```text
experiments/ri3d_datasets/first2/
```

Server GPU runner:

```bash
bash scripts/run_ri3d_first2.sh
```
