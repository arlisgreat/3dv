# Historical Pseudo-View Candidate Pools

This directory name is historical. Its contents are pseudo-view candidate-pool
exports, not validated reconstruction datasets and not approved training inputs.

The current repository rule is:

```text
do not train from this directory unless a later milestone records
PASS_REAL_GT_BENCHMARK for a real captured benchmark case.
```

As of 2026-05-20, G21 records PASS_REAL_GT_BENCHMARK only for a local Multiface
debug real-capture case under `3dv_work`. That pass does not authorize training
from this pseudo-view candidate-pool directory. The old pseudo-view and RI3D
route is retained only for diagnostic/failure-taxonomy value.

Generated by:

```bash
python3 scripts/build_downstream_dataset.py --overwrite
```

## Variants

```text
raw75_all6/
```

All six raw Zero123++ `steps=75` views for each first10 sample. This is an
unsafe diagnostic baseline.

```text
raw75_budget4/
```

Four raw Zero123++ `steps=75` views selected by CLIP/reliability ranking. This
records whether ranking improves candidate hygiene, not whether reconstruction
training is valid.

```text
cutout75_budget4_masked/
```

Subject-cutout Zero123++ `steps=75` views selected by CLIP/reliability budget4
and filtered by trusted-region acceptance. This was the strongest historical
candidate-pool frontend, but corrected 3x2 visual audit still found visible
identity and geometry distortions.

## Per-Sample Layout

Each sample contains:

```text
images/
masks/
metadata.json
```

`metadata.json` records:

```text
sample_id
variant
source_run
selected view indices
azimuth / elevation
image path
mask path
trusted score
reliability score
reject reasons
```

## Historical Comparison

These variants were used for diagnostic downstream comparisons:

```text
A: LAM single-image baseline
B: raw75_all6 or raw75_budget4
C: cutout75_budget4_masked
```

The result of G8-G19 is that safer 2D candidate hygiene does not prove valid 3D
supervision. The next credible route is a licensed real-GT benchmark with real
captured views, cameras, masks, and GT mesh/point cloud.

## RI3D Conversion

RI3D does not read this tool-agnostic layout directly. Convert the selected
first2 pilot scenes with:

```bash
python3 scripts/prepare_ri3d_dataset.py --overwrite
```

Converted output:

```text
experiments/ri3d_datasets/first2/
```

Historical server GPU runner:

```bash
bash scripts/run_ri3d_first2.sh
```

Do not run this as a new quality experiment. G21 passes only for the real
captured Multiface benchmark case, not for these generated pseudo views.
